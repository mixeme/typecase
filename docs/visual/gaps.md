# Пробелы: кадры, которые не собираются из виджетов

Кадр-маршрут (Р-16, [development.md](../development.md)), которого не собрать
из виджетов библиотеки, записывается сюда и не собирается обходом на экране.
Пробел закрывается по правилу пробела ([development.md](../development.md),
«Пробел»): кадр или фрагмент в макете, затем виджет с эталоном, затем экран. Строка уходит из таблицы, когда у кадра есть маршрут и
он проходит статическую сверку. Ворота `frame-coverage` держат таблицу честной:
кадр-маршрут есть либо в маршрутах, либо здесь, но не там и там сразу.
