# Пробелы: кадры, которые не собираются из виджетов

План 3, шаг 1. Кадр-маршрут (Р-16), которого не собрать из виджетов
библиотеки, записывается сюда и не собирается обходом на экране. Пробел
закрывается по правилу шага 5: кадр или фрагмент в макете, затем виджет с
эталоном, затем экран. Строка уходит из таблицы, когда у кадра есть маршрут и
он проходит статическую сверку. Ворота `frame-coverage` держат таблицу честной:
кадр-маршрут есть либо в маршрутах, либо здесь, но не там и там сразу.
