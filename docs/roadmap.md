## Как работать с этой серией

Правила владельца — в памяти сеанса и в [development.md](development.md):
вопросы — по одному; картинки — частями по 3–4 с тем, куда смотреть;
известный дефект чинится до показа; правки цифр и данных кадров — без
владельца, в пользу полноты набора; записки в Carrel пишутся без
подтверждения (с 14.10), одним файлом `docs/plan/from-typecase.md`;
коммиты — прямо в `main`, пушит владелец.

- **Правка кадра:** макет (`docs/visual/carrel-ui-mockups.html`, LF;
  правка скриптом с проверкой числа замен) → `go generate ./css` (если
  менялся CSS) → `go generate ./internal/screens` → `go test ./internal/refs
  ./internal/gate`. Генератор не собирается, пока старые экраны ссылаются
  на убранное поле: вернуть поле временно, сгенерировать, убрать.
- **Записи-эталоны** (`internal/framegen/cmd/record/`): `refresh.py
  кадр:класс:N` — значение заново из кадра (`--force`, если меняется
  вариант или тон); `add.py кадр:класс:N:состояние` — новая форма (имя
  состояния не должно звать предмет — шлюз domain-naming); `remove.py`;
  `hintfix.py` — номера по подсказкам теста, до «0 hints»; затем `gofmt -w
  internal/refs`. `TestShapesCovered` называет форму без записи; повтор `ID`
  в записях (unique-ids) — убрать `ID` из второй. Число кадров — в
  `internal/gate/mockup_lint_test.go`, фрагментов — в
  `internal/catalog/ladder_test.go`.
- **Кадр маршрута листа** собирается из тела экрана-источника (`tc-top` +
  `tc-shell__body--minh560`, без `tc-side`) и формы листа в `tc-scrim
  tc-scrim--padt26`; дополнительный кадр — со словами «дополнительный кадр:
  …» в ярлыке. Мёртвое правило CSS после правки — убрать из `<style>`
  макета и вариант виджета, который его печатал.
- **Перед коммитом:** весь набор без браузера (`go test $(go list ./... |
  grep -v internal/browser)`) и лестница (`go test ./internal/browser -run
  '^TestMockupLadder$' -timeout 40m -v`, ~5–11 минут). Правка CSS —
  `TestMockupStrays` (Р-52): правленые кадры названы, неправленые сверены с
  HEAD; общее правило меряет сотни кадров — делить `TC_STRAYS_ONLY` на
  части. Правка JS — все тесты поведения (`-skip
  'Mockup|FramesLadder|Catalog'`, ~12 минут). Новый `\n` в JS — через Edit,
  не python-вставкой из bash.
- **Снимки:** `TC_FRAME_SHOTS=<кадр>[@ширина]` (несколько — через запятую),
  `TC_FRAME_SHOTS_DIR` — путь от `internal/browser`; «до» —
  `TC_FRAME_SHOTS_REV=HEAD`; сравнение — `python internal/browser/pixdiff.py
  до после` или `bash internal/browser/pixpair.sh <кадры>`. Фрагмент без
  ширины снимается во всю ширину. Снимки и лестницу одновременно не гонять
  (один Edge); свои зависшие Edge (`typecase-browser-*`) закрывать, чужие не
  трогать.
- **Временное** — только в `dev/` (в git не попадает): `GOCACHE="$PWD/dev/_gocache"
  GOTMPDIR="$PWD/dev/_gotmp"`; папки с кодом Go в ней начинаются с `_`. Вне
  репозитория — только с разрешения владельца.
- **Принятое при непринятом в дереве** — временная копия (`git worktree add
  --detach`), перенос нужных участков, `git diff` → `git apply --cached`.
